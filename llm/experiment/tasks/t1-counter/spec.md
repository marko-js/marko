# Task: Like button

Build a single page with Marko 6 (the tags API). The app is served by @marko/run's dev server; `marko` and `@marko/run` are already installed. Create the page at `src/routes/+page.marko`.

## Requirements
- The page shows a button with the attribute `id="like"`.
- The button's text is exactly `Likes: N` where N is the current number of likes, starting at 0.
- Each click of the button increases the count by 1 and the button text updates.

## Output
Return every file you create (paths relative to the app root).
